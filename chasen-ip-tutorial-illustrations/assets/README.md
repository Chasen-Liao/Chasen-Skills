# 角色参考资产目录（由用户或私有配置提供）

本公开仓库不内置任何个人专属 IP 角色图片。

使用 `chasen-ip-tutorial-illustrations` 前，请将你自己的角色参考图放入本目录（或通过私有配置/工作区路径提供），推荐结构如下：

```text
assets/
├── character-contract.md   # 你的角色设计契约与 Character Lock（可选，或由会话提供）
├── master-立绘参考.png      # 主参考真源（必传 Image 1）
├── 角色设定卡.png           # 三视图与色卡补充（按需）
└── 头像-透明.png            # 头像/表情补充（按需）
```

若还没有自己的角色资产包，可先使用本仓库的 [`personal-ip-builder`](../../personal-ip-builder/README.md) 从照片、参考图或纯文字生成专属角色真源。
