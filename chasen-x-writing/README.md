# chasen-x-writing

把 Chasen 的口播/碎片想法，写成他本人语气的 𝕏 帖或长文。

## 结构（路由）

`SKILL.md` 是总入口，按场景再读子文件，不要把所有风格挤进一个文档：

| 文件 | 何时读 |
|---|---|
| `align.md` | 开写前对齐观点 |
| `draft-types.md` | 定分享/实测/快评/长文 |
| `traffic.md` | 浏览/收藏/回复目标、8 种帖型、数字与钩子细则 |
| `voice-and-craft.md` | 通顺、事实、声音、去 AI 味 |
| `deliver.md` | 三问与交付格式 |
| `references/` | 语感样本与结构参考 |

账号运营习惯（热点连发、收藏夹拆解）不在本 skill。

## 安装

```bash
npx skills add Chasen-Liao/Chasen-Skills --skill chasen-x-writing --global --yes
```

## 用法

丢思路或链接并加载本 skill。Agent 应先走 `align.md`，再按路由读其余文件后出稿。
