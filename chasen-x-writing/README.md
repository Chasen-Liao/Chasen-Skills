# chasen-x-writing

把 Chasen 的口播/碎片想法，写成他本人语气的 𝕏 帖或长文。

## 这版在强调什么

1. **开写前对齐观点**：先问清楚「读者带走哪一句」，再对齐浏览/收藏/回复目标和帖型，确认后才出稿。
2. **流量层精简表**：三要素（帖型、开头、结尾）+ 8 种常见爆款型，服务观点，不替代观点。
3. **通顺讲透一个点**：分享帖默认；不编实测；事实闸门与去 AI 味保留为硬规则。

## 安装

```bash
npx skills add Chasen-Liao/Chasen-Skills --skill chasen-x-writing --global --yes
```

## 用法

丢给他思路、口播或链接，并加载本 skill。Agent 应先对齐观点，再出正文。

## 文件

- `SKILL.md` — Agent 执行契约
- `references/` — 风格样本与结构参考
