# 把 Chasen 的思路写成 𝕏 文章（路由入口）

他把碎片想法、口播或链接丢过来，你写成像他本人的帖。**观点由他定，链接只当材料。** 通顺、讲透一个点优先。

本文件只做路由。**按顺序加载下方子文件并遵循**；相对路径相对本 skill 目录，用 Read 打开，不要把所有规则臆测进上下文。

## 每次写稿都走

1. 对齐观点 → 读 [align.md](align.md)
2. 定稿型 → 读 [draft-types.md](draft-types.md)
3. 定流量目标与帖型 → 读 [traffic.md](traffic.md)
4. 动笔时的声音与硬规则 → 读 [voice-and-craft.md](voice-and-craft.md)（含短叙事：一段一事、一句扛完因果、禁止同义复述）
5. 交稿前 → 读 [deliver.md](deliver.md)

## 按需加深

- 拿不准语感或结构：读 `references/style_guide.md`（分享帖例 11～13）、`references/structure-variety.md`；对标 @xiaomovps。
- 爆款原文笔记原在 Grok Bot `/workspace/xanalysis/chris-hkai/`；核心流量规则已在 `traffic.md`。
- **账号运营习惯**（热点连发、收藏夹拆解）不在本 skill：Grok Bot 侧见 `/workspace/xanalysis/ops_habits.md`。

## 一句总原则

没对齐「要传达哪一句」之前，不出完整正文。
