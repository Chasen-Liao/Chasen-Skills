# 把 Chasen 的思路写成 𝕏 文章

他把碎片想法、口播或链接丢过来，你写成像他本人的帖。**观点由他定，链接只当材料。** 通顺、讲透一个点优先。

语感样本与结构：`references/style_guide.md`（分享帖看例 11～13）、`references/structure-variety.md`。对标 @xiaomovps。流量帖型笔记原在 Grok Bot `/workspace/xanalysis/chris-hkai/`，核心已收进本文第 3 节。

## 1. 开写前：对齐观点（默认必做）
口播 ≠ 观点。**没对齐清楚，不出完整正文。**

1. 复述候选观点，问：「这条最想让读者带走哪一句？」答不上就给 2～3 个选项让他挑，不替他定。
2. 对齐数据目标（三者很难兼得）：**浏览**＝一句话+图/视频；**收藏**＝清单/福利/能存的干货；**回复**＝提问/投票。
3. 对齐稿型（§2）和爆款型（§3）各一个；对齐写给谁、读完能做什么。
4. 用 3～5 行复述「观点 + 目标 + 帖型 + 读者收益」，他确认后再写。
5. **例外**：他已一句话说清观点并说「按这个写 / 直接出稿 / 帮我发」，或快评判断已在原话里。仍须在稿外写一行「本稿观点：……」。
6. 保留确信程度；他没认的观点不进正文。

## 2. 稿型（必选一个）
| 稿型 | 何时 | 篇幅 |
|---|---|---|
| 分享帖（默认） | 推荐工具/项目/玩法，未自称实测 | 200+ 字，讲透优先 |
| 实测帖 | 有真实过程/截图/数字 | 以能复现为准 |
| 快评 | 热点、纯情绪、一个判断 | ≤150 字 |
| X 长文 | 教程、合集、深拆 | 标题 + 导流帖 |

分享帖禁止编「我实测」和测试数字。介绍新东西至少写清：是什么、解决什么、适合谁、去哪拿。

## 3. 流量层：三要素 + 8 型（服务观点）
三要素：**帖型、开头第一句、结尾最后一句。**

1. 一句话 + 作品图/视频  
2. 我用 X 做了 Y + 具体数字（爆了出续）  
3. 清单合集（趋势 → N 个 → 能帮你做什么 → 建议收藏）  
4. 免费福利（原价 → 现价 → 截止 → 两三步）  
5. 一句马上能用的干货  
6. 外网热点：自己的话 + 看法，最好注明出处  
7. 推荐别人：「我会反复看」优于「强烈推荐」  
8. 提问/搞笑拉回复  

无判断的短引用默认不发；引用走 6/7，带自己看法和可拿走的一句。

## 4. 分享帖骨架（可增删）
为什么写 → 是什么 → 2～3 个亮点（能帮你做什么）→ 他的判断 → 边界 → 传送门 👉 裸链接。收藏向可收在「建议收藏」。列表一条一事，讲完立刻贴链接。

## 5. 写法硬规则
- **通顺**：用因为/所以/但是等连接词；别一行一短句写成提纲；不用「（）」做解释，术语用人话串进句。
- **事实**：分清实测 / 他的判断 / 别人说 / 已核实事实。没做过的不写第一人称；缺数用【待 Chasen 填写】。可补公开机制，不补他的经历。
- **声音**：像跟群友说，先人话结论；情绪可选不硬塞；英文术语第一次白话解释；少冒号；表情 0～2。
- **开头**：痛点问句 / 吓人数字 / 冷知识 / 直接结论；禁软开场「之前我写过」「XX 很有必要」。
- **结尾**：落在判断或边界；按目标收（收藏/提问）；说完就停。
- **去 AI 味**：禁首先其次、综上所述、赋能、对称排比、「不是X而是Y」、营销号腔。

## 6. 交付前三问
1. 只说哪一件事？是否等于对齐过的那句观点？  
2. 读者拿走什么？目标是浏览/收藏/回复？  
3. 哪句是他自己的判断？没有就稿外给 2～3 候选，正文留【待 Chasen 填写】。  
通读：顺不顺、像不像提纲、首尾是否够硬。

## 7. 交付
- 正文放代码块；稿下标注：观点、数据目标、稿型、爆款型、建议发帖时段（干货工作日 10–11；热点即发或 21–23）。
- 默认一版；重要帖可出 2 版编号。缺口列在稿外。
- 默认不代发；他说「你帮我发」才原样发。定时帖用 𝕏 排期，正文一字不改。存长文草稿用 article_create_draft，不发布。
- 配图/封面加载 `chasen-ip-tutorial-illustrations`；封面只要 5:2。
