# 把 Chasen 的思路写成 𝕏 文章（路由入口）

他把碎片想法、口播或链接丢过来，你写成像他本人的帖。**观点由他定，链接只当材料。** 通顺、讲透一个点优先；**人味优先于爆款公式**。

本文件只做路由。**按顺序加载下方子文件并遵循**；相对路径相对本 skill 目录，用 Read 打开，不要把所有规则臆测进上下文。

## 铁律（2026-11-05）

1. 读起来要像他跟群友说话，不像小论文、不像填空爆款模板。
2. Chris 8 型 / 硬钩子是**可选加速器**，只服务明确要冲浏览或收藏的帖；口播观点默认不套。
3. 他已经口语讲清「好奇→以为→发现」时，选「口播观点」稿型，篇幅跟着他走；调研数字放稿外。
4. 禁止「先说清楚」划界段、百分比墙、机械总结腔、为互动硬加的结尾提问。

## 每次写稿都走

1. 对齐观点 → 读 [align.md](align.md)
2. 定稿型 → 读 [draft-types.md](draft-types.md)（口播观点优先于硬拉分享长帖）
3. 定流量目标与是否套帖型 → 读 [traffic.md](traffic.md)
4. 动笔时的声音与硬规则 → 读 [voice-and-craft.md](voice-and-craft.md)
5. 交稿前 → 读 [deliver.md](deliver.md)

## 按需加深

- 拿不准语感或结构：读 `/workspace/chasen-writing/style_guide.md`（分享帖例 11～13）、`structure-variety.md`；对标 @xiaomovps。口播观点优先看 `voice-and-craft.md` 正例。
- 爆款原文笔记：`/workspace/xanalysis/chris-hkai/`（冲量时参考，不覆盖人味铁律）。
- **账号运营习惯**（热点连发、收藏夹拆解等，不是文案规则）：`/workspace/xanalysis/ops_habits.md`。

## 一句总原则

没对齐「要传达哪一句」之前，不出完整正文。对齐之后，先写成他会发的话，再考虑要不要套公式。
