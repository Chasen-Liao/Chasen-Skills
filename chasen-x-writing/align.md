# 开写前：对齐观点（默认必做）

口播 ≠ 观点，**没对齐清楚不出完整正文**

1. 复述候选观点，问：「这条最想让读者带走哪一句？」答不上就给 2～3 个选项让他挑，不替他定
2. 对齐数据目标（见 `traffic.md`）；他说「随便写写 / 发个观点」时，默认「无冲量」，不要自作主张选浏览/收藏公式
3. 对齐稿型（`draft-types.md`）：他已用口语讲完「好奇→以为→发现」时，优先「口播观点」，不要默认分享帖干货骨架；爆款型仅在要冲量时再选
4. 用 3～5 行复述「观点 + 目标 + 稿型 + 读者收益」，他确认后再写；他原话已经是可发长度时，复述确认即可，**不要承诺扩写成长调研**
5. **例外**：他已一句话说清观点并说「按这个写 / 直接出稿 / 帮我发」，或快评判断已在原话里，仍须在稿外写一行「本稿观点：……」
6. 他只丢一句话或素材很少时，先问再写（见 plain-talk.md 第三部分）
7. 保留确信程度，他没认的观点不进正文；调研补充写在稿外，除非他要数据进正文
