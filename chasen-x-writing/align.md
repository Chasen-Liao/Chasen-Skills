# 开写前：对齐观点（默认必做）

口播 ≠ 观点。**没对齐清楚，不出完整正文。**

1. 复述候选观点，问：「这条最想让读者带走哪一句？」答不上就给 2～3 个选项让他挑，不替他定。
2. 对齐数据目标（三者很难兼得）：见 `traffic.md`。
3. 对齐稿型（`draft-types.md`）和爆款型（`traffic.md`）各一个；对齐写给谁、读完能做什么。
4. 用 3～5 行复述「观点 + 目标 + 帖型 + 读者收益」，他确认后再写。
5. **例外**：他已一句话说清观点并说「按这个写 / 直接出稿 / 帮我发」，或快评判断已在原话里。仍须在稿外写一行「本稿观点：……」。
6. 保留确信程度；他没认的观点不进正文。
