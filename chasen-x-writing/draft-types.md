# 稿型（必选一个）

| 稿型 | 何时 | 篇幅 |
|---|---|---|
| 口播观点（好奇/自查/吐槽） | 他口述一个判断、好奇查完有结论、随手观点 | 约 80～250 字，2～3 段口语 |
| 分享帖 | 推荐工具/项目/玩法，未自称实测 | 200+ 字，讲透优先 |
| 实测帖 | 有真实过程/截图/数字 | 以能复现为准 |
| 快评 | 热点、纯情绪、一个判断 | ≤150 字 |
| X 长文 | 教程、合集、深拆 | 标题 + 导流帖 |

**口播观点是默认优先项**，当他用口语讲清观点、或选题是「我好奇→查了一下→发现」时，选它，不要默认拉成分享帖/干货长帖。

分享帖禁止编「我实测」和测试数字。介绍新东西至少写清：是什么、解决什么、适合谁、去哪拿。

## 口播观点骨架（松，可增删）

现象或好奇 → 自己原先以为 → 查完/想完之后发现啥。  
不要 taxonomy 划界段，不要调研百分比墙，不要硬结尾提问。

## 分享帖骨架（可增删）

为什么写 → 是什么 → 2～3 个亮点（能帮你做什么）→ 他的判断 → 边界 → 传送门 👉 裸链接。收藏向可收在「建议收藏」。列表一条一事，讲完立刻贴链接。
