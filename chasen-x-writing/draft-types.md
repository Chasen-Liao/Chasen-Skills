# 稿型（必选一个）

| 稿型 | 何时 | 篇幅 |
|---|---|---|
| 分享帖（默认） | 推荐工具/项目/玩法，未自称实测 | 200+ 字，讲透优先 |
| 实测帖 | 有真实过程/截图/数字 | 以能复现为准 |
| 快评 | 热点、纯情绪、一个判断 | ≤150 字 |
| X 长文 | 教程、合集、深拆 | 标题 + 导流帖 |

分享帖禁止编「我实测」和测试数字。介绍新东西至少写清：是什么、解决什么、适合谁、去哪拿。

## 分享帖骨架（可增删）
为什么写 → 是什么 → 2～3 个亮点（能帮你做什么）→ 他的判断 → 边界 → 传送门 👉 裸链接。收藏向可收在「建议收藏」。列表一条一事，讲完立刻贴链接。
