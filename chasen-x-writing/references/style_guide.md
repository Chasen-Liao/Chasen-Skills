# 𝕏 个人写作风格画像模板

> **说明**：本文件为公开通用模板，不包含具体个人的年龄/学历/职业背景、私有推文语料或实测曝光数据。使用本 Skill 时，请将你的个人画像、真实高赞原文样本与账号时段统计放在独立私有配置中覆写，避免写入公开仓库。具体执行铁律以 `../SKILL.md` 为准。

## 1. 人设与口吻（由使用侧填入）

- **账号标识**：`<your-x-handle>`（不写入公开模板）
- **作者定位**：`<你的核心领域与一线实操标签，例如：独立开发者 / AI 工具实践者 / 后端工程师>`
- **说话方式**：第一人称「我」，像跟同好聊天；允许自然情绪表达与适度自嘲，避免端着的报告腔与宣讲口吻。
- **专业感来源**：实测帖靠真实步骤、命令、版本号与对比结果；分享帖靠讲清「是什么、解决什么、适合谁、自己的取舍」，不空谈概念。

## 2. 常用词、表情与标点约定

- **高频自然过渡词（按个人习惯替换）**：`感觉`、`其实`、`翻了一下`、`试了一波`、`才发现`、`有一说一`
- **标点与排版**：
  - 手机阅读优先短段多换行；口播短帖优先用空行断句，少用句号「。」（情绪留白可用「。。。」）。
  - 引导链接可用「传送门 👉」或直接裸链。
  - Emoji 与编号严格遵守 `../SKILL.md` 铁律第 7 条：正文少用、最多 1 个点睛，严禁 `1️⃣2️⃣3️⃣` 数字 emoji 编号。
- **情绪词定位**：纯情绪词（如「哈哈哈」「牛」）适合作为调味，不宜单独撑起无信息增量的短引用。

## 3. 篇幅分层策略

| 形态 | 篇幅 | 适用场景 | 写法要点 |
| :--- | :--- | :--- | :--- |
| **一句话快评** | ≤40 字 | 热点首发、强观点、情绪共鸣 | 直给判断或疑问，最好配图，不铺垫 |
| **口播短帖（默认）** | 80～250 字 | 日常观察、好奇自查、轻量观点 | 2～3 段口语自然收尾，不硬塞列表与调研百分比 |
| **干货 / 实测长帖** | 300～1,500 字 | 工具实测、三步教程、深度拆解 | 痛点钩子 → 问题背景 → 具体步骤/命令与验证标准 → 个人判断 → 风险放最后 → 传送门 |
| **X 长文（Article）** | 1,500 字以上 | 系统指南、完整合集 | 仅存草稿，另配简短导流帖 |

## 4. 低表现常见避坑

- 只转发/引用不加信息增量或个人判断的一句空评。
- 原样搬运新闻而不说明「这件事对读者有什么影响」。
- 脱离实际步骤硬凑编号列表，或用「总结一下 / 你们觉得呢」机械收尾。
- 缺少具体场景、命令、数字或截图支撑的抽象形容词堆砌。

## 5. 发帖时段校准（用你自己的数据）

不要套用他人账号的历史曝光表。建议定期导出你的 X Content Analytics CSV，运行本仓库 [`x-analytics`](../../x-analytics/README.md) 还原本地时区黄金档，并将结果记入你的私有配置：

- **干货 / 长帖**：优先放在你账号实测曝光与收藏均值较高的工作日时段。
- **热点快评**：时效优先于卡点，重大发布或热点事件出现后尽早发出。
- **低迷时段**：避开你实测表现持续偏低的周末或凌晨窗口发重磅长帖。
