# 流量层：目标、三要素、8 型与写法细则

服务已对齐的观点，**不替代观点，更不压过人味**。

## 先选数据目标

| 目标 | 常见写法 | 注意 |
|---|---|---|
| 浏览 | 一句话 + 图/视频 | 冲量；收藏往往极低，通常不涨粉 |
| 收藏 | 清单 / 福利 / 能存的干货 | 结尾可写「建议收藏」 |
| 回复 | 提问 / 投票 / 二选一 | 互动向，别硬塞长干货 |
| 无冲量（默认） | 口播观点照实写 | 很多帖不需要冲；别为冲量毁人味 |

**流量 ≠ 涨粉**：冲浏览的帖往往没人存；要涨粉靠值得收藏的创作，或高转化的热点长文。

## 三要素

帖型、开头第一句、结尾最后一句。口播观点帖允许「软」开头（好久没看到……），不要为了公式改成吓人数字或痛点问句。

## 8 种常见爆款型（可选，不是每帖必套）

**只在他明确要冲浏览/收藏，或稿型是分享清单/福利/实测冲收藏时选用一个。** 口播观点、随手判断、好奇自查默认**不套**。

1. 一句话 + 作品图/视频  
2. 我用 X 做了 Y + 具体数字（爆了出续；可用「你们喜欢上一条」+ 更大数字）  
3. 清单合集：趋势 → 挑了 N 个 → 每项能帮你做什么 → 建议收藏  
4. 免费福利：原价 → 现价/免费 → 截止 → 两三步  
5. 一句马上能用的干货  
6. 外网热点：自己的话 + 看法，最好注明出处  
7. 推荐别人：「我会反复看 / 每周都会重读」优于「强烈推荐」  
8. 提问/搞笑拉回复；搞笑常用前两段正常、第三段抖包袱  

无判断的短引用默认不发；引用走 6/7。

## 写法细则（冲量帖才加重；口播帖从轻）

1. **数字要具体**：334 个零件、9 美元、10 分钟，胜过「很多」「很快」。口播帖没有数字就别硬编。  
2. **免费必须有价格锚点**：没有原价对比，「免费」没分量。  
3. **推荐语用关系，不用空形容词**：「我会反复看」>「强烈推荐」。  
4. **搞笑三段式**：前二铺垫，第三抖包袱。  
5. **开头与结尾**：冲量帖禁「之前我写过」这类软开场；口播观点帖允许「好久没……」「这玩意……」这种他本人常用的起手。结尾按目标收；无冲量就自然停，严禁为互动硬加提问（见 voice-and-craft.md）。
