# 通顺、事实、声音、去 AI 味

- **通顺**：用因为/所以/但是等连接词；别一行一短句写成提纲；不用「（）」做解释，术语用人话串进句。
- **短叙事 / 故事帖硬卡**（口播改写、分享过程尤其适用）：
  1. **一段一事**：每一段只推进一个信息点，不要把拆解、沉淀、公开拆成三段进度条。
  2. **一句扛完因果**：能用「把 A 直接写成 B」说完的，不要先写「拆出了」，再另起一句「写进了」。
  3. **禁止同义复述**：正文里同一动作只出现一次；前面说了「写进 skill」，后面禁止再用「做成了 skills / 深度拆解完之后」回炉。
  4. 交稿前出声读一遍：若两句可以并成一句且不丢信息，就并；若某句只是换词重复，就删。
- **事实**：分清实测 / 他的判断 / 别人说 / 已核实事实。没做过的不写第一人称；缺数用【待填写】。可补公开机制，不补他的经历。
- **声音**：像跟群友说，先人话结论；情绪可选不硬塞；英文术语第一次白话解释；少冒号；表情 0～2。
- **去 AI 味**：禁首先其次、综上所述、赋能、对称排比、「不是X而是Y」、营销号腔。
