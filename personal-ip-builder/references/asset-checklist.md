# 核心资产验收清单

## 必备文件

- [ ] 用户已明确锁定 master，路径写入 character-contract.md
- [ ] 角色设定卡 1 张：正 / 侧 / 背三视图 + 配色条 HEX
- [ ] 视觉规范卡 1 张：干净的定稿参考图，单人物，浅底或透明底
- [ ] character-contract.md：固定特征、禁止漂移项、线条配色、Character Lock
- [ ] 透明头像 1 张
- [ ] 静态表情 4～6 个，透明 PNG

## 一致性

- [ ] 发型、配件、服装、配色跨图稳定，与 master 一致
- [ ] 侧面是真侧面，背面无正面五官
- [ ] 表情遮住标签后仍可区分
- [ ] 未复刻参考图受保护细节

## 可用性

- [ ] 头像在圆形裁切下，脸和识别配件仍可辨
- [ ] 设定卡配色条写了 HEX，与画面一致
- [ ] 规范卡干净，没有把版式装饰画进角色参考里

## 不要当作本包必交

封面、背景图、日常配图、场景图、GIF 都不在本清单里。
