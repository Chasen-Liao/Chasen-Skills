# 整套数字资产验收清单

第一层交付用。设定板不过关，不要勾选 3–8 的批量项。

## 必备文件

- [ ] `character-contract.md`（已由用户确认）
- [ ] 01 角色设定板
- [ ] 01 视觉规范板
- [ ] 02 头像
- [ ] 02 全身立绘
- [ ] 03 表情与动作 4–6 个状态
- [ ] 04 内容场景至少 1–4 张
- [ ] 05 贴纸或反应图
- [ ] 横版主视觉

## 一致性

- [ ] 发型、配件、服装、配色、品牌符号跨图稳定
- [ ] 侧面是真侧面，背面无正面五官
- [ ] 表情格遮住标签后仍可区分
- [ ] 未复刻参考图的脸、服装、构图、Logo

## 画面规则

- [ ] 纯白背景、深灰手绘线稿、清爽平涂
- [ ] 单图单核心意思，不过满像 PPT，不是多格拼图
- [ ] 角色在做事，是动作主体，不是站立微笑证件照
- [ ] 缩略图下轮廓与配件仍可辨
- [ ] 无多余肢体、断肢、乱码文字、水印、第三方 Logo
