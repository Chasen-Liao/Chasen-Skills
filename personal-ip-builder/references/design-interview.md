# 设计访谈预设包（Stage 1–2）

> 原则：每轮打包 3～5 问并附推荐选项；已确认项跨轮锁定不重复问；信息够生成 `master-立绘参考.png` 就停，不把用途展开成封面/场景制作清单。

---

## 一、第一轮优先对齐 5 件事

1. **输入与原创边界**：用下表哪条路径？哪些特征保留，哪些必须原创化？
2. **画风与头身比**：从速选表选定（无偏好时推荐「Q 版手绘平涂 / 3～3.5 头身 / 浅底」）。
3. **第一眼记忆点**：发型发色、固定服装、1 个识别配件、主/辅/点缀色、品牌符号（如有）。
4. **身份与性格**：本人分身还是虚构角色？一句话内容定位与 2～3 个可驱动画面的性格词。
5. **首批 4～6 个静态表情**：直接匹配创作者内容里最常出现的情绪（可从赛道推荐包勾选）。

---

## 二、三类输入路径预设

开场先问：「手头有没有想参考的**本人照片**、**喜欢的角色/画风图**，或者想直接**纯文字从零设计 / 升级旧头像**？」按用户选择走对应预设：

| 输入路径 | 先问与确认重点 | 保留边界（写入契约） | 必须原创化 / 改写项 |
| :--- | :--- | :--- | :--- |
| **A. 照片转 IP** | 问清要保留哪 2～3 个真人标志（发型、眼镜、耳饰、痣/酒窝、常穿单品） | 只保留用户点名的辨识特征与整体气质 | 脸型五官按目标画风简化提纯；服装升级为更易辨识的固定 IP 穿搭 |
| **B. 参考图借气质** | 问清喜欢这张图的什么（配色氛围、头身比、笔触质感、性格气场） | 仅保留抽象视觉语言与情绪方向 | **必须 100% 重做**五官细节、发型局部、服装结构、构图、第三方 Logo 与符号 |
| **C. 无图从零设定 / 旧头像升级** | 问清内容赛道、想给观众的第一印象、有无现成品牌主色或口头禅/标志物 | 若有旧头像，只留核心记忆点（如帽子、配色或动物耳） | 补齐全身比例、服装上下装、主辅点缀色 HEX 与可识别配件 |

---

## 三、画风与头身比速选表

用户没有明确偏好时，推荐第 1 项「Q 版手绘平涂」作为默认；若用户另有偏好，直接锁定对应画风并在后续阶段严格沿用。

| 画风选项 | 推荐头身比 | 线条与上色特征 | 适合内容调性 | Stage 4/5 适配提醒 |
| :--- | :--- | :--- | :--- | :--- |
| **1. Q 版手绘平涂（无偏好默认）** | 3～3.5 头身 | 干净深灰/暖黑手绘线稿，清爽平涂，少量柔和阴影 | 教程讲解、技术博客、轻知识科普 | 留白易读，适合极简批注与信息图露头 |
| **2. 日系赛璐璐** | 4～6 头身 | 精细闭合线稿，明确二分硬阴影与高光层次 | 二次元、游戏、ACG 杂谈、剧情向输出 | 三视图需严格保持头发分缕与眼部高光一致 |
| **3. 扁平矢量 / 美式卡通** | 2.5～4 头身 | 粗细匀称几何轮廓（或无边色块），高饱和撞色 | 商业解读、效率工具、欧美风播客/Newsletter | 表情与手势轮廓要大，缩放至头像框依然锐利 |
| **4. 像素风（Pixel Art）** | 2～3 头身 | 固定像素网格感、有限色盘、无模糊抗锯齿 | 独立游戏、Retro 极客、复古编程项目 | 三视图与表情需保持同一像素颗粒度，禁止半透明渐变糊边 |
| **5. 3D 盲盒 / 粘土潮玩** | 2～2.5 头身 | 哑光 PVC/磨砂粘土材质、柔和全局光、圆润体积感 | 潮玩开箱、消费电子评测、Lifestyle 品牌 | 透明 PNG 去背注意保留干净边缘，避免环境反光污染背景 |
| **6. 半写实插画** | 5.5～7 头身 | 弱化外轮廓或细线稿，体积光影与肤质/布料细节 | 深度长评、人物访谈、文艺/美学专题 | 表情切换重在眉眼与姿态变化，避免 Q 版化走形 |

## 四、按创作者赛道的 4～6 个静态表情推荐包

引导用户直接勾选或微调一组（要求：**遮住名字后仍能靠表情与手势一眼分清**）：

| 创作者赛道 | 推荐表情包（选 4～6 个） | 视觉动作建议（无字可辨） |
| :--- | :--- | :--- |
| **AI / 技术教程** | 1. 灵光一闪 / 2. 专注敲代码 / 3. 报错崩溃 / 4. 搞定比耶 / 5. 摊手困惑 / 6. 认真指重点 | 灯泡/亮眼、盯屏托腮、冒汗抓头、比耶微笑、歪头摊手、举手指向侧方 |
| **Vlog / 生活日常** | 1. 元气早安 / 2. 开心干饭 / 3. 社恐躲角落 / 4. 疯狂点赞 / 5. 委屈叹气 / 6. 放空摸鱼 | 挥手灿笑、捧碗星星眼、抱膝缩角、双手拇指、垂眼叹气、托脸发呆 |
| **评测 / 商业带货** | 1. 惊喜种草 / 2. 冷静挑刺 / 3. 真香打脸 / 4. 举牌推荐 / 5. 钱包空空 / 6. 稳妥过关 | 双眼放光、扶镜/抱臂审视、捂脸惊讶、双手托举展示、翻空口袋、点头 OK |
| **知识 / 观点评论** | 1. 抛出暴论 / 2. 陷入沉思 / 3. 吃瓜围观 / 4. 严肃划重点 / 5. 无语翻白眼 / 6. 鼓掌认可 | 食指上指、托下巴微皱眉、捧茶/瓜暗笑、推镜前倾、半月眼斜视、鼓掌微笑 |

## 五、补漏追问清单（仅在首轮信息不足时按缺口提问）

若首轮回答已覆盖以下内容，**直接进入阶段 3 试定稿**；仅对缺失项做 1 轮紧凑追问：

- 配色：主色 / 辅色 / 点缀色是否还没定？（可代为推荐 1 套主辅点缀色搭配供确认）
- 识别记忆点：是否还缺一个「一眼认出是他」的配件或符号？（如特定耳机、眼镜框、发卡、胸针、袖标字母）
- 性格驱动：性格词是否太抽象（如「温柔」）？转译成可画的动作线索（如「爱托腮思考、经常一边比划一边讲解」）。
