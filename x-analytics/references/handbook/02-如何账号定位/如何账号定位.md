# 如何账号定位

如果你还不知道自己应该定位在什么赛道,那么可以看一下以下几个热门方向:

1. 赚钱相关话题
2. 学英语
3. AI
4. 夫妻生活、创业故事
5. 心灵鸡汤、读书分享

这些基本是现在比较热门的赛道,选一项适合自己的就行。

这里**不推荐用产品账号**。如果你想推广自己的产品,正确的做法是讲自己的创业故事,打造个人IP,以此来推广你的产品。

在X上面,你需要展示自己个人化、情感化、活生生的一面,而不是冷冰冰的产品宣传。

如果你不知道走什么赛道,**我推荐你走AI赛道**,原因如下:

1. **AI是未来的趋势**,做AI的自媒体会强迫自己去学习相关知识、了解AI工具,用输出倒逼自己输入
2. **AI的内容比较好做**,信息非常好获取,哪怕只是做个信息的搬运工也能获取到不少流量
3. **现在AI产品越来越多**,需要更多的人帮忙宣传,所以商单也会比较多

# 语言定位

很多人一开始就走偏了方向,其实**定位真的决定你能不能起飞**。

定位清晰,你的内容会更集中,你的粉丝会更精准,你的爆文率也会更高。

关于语言定位,我的建议很简单:**母语是什么,就用什么语言做账号**。

如果你是中文圈的朋友,我真心建议你就做纯中文账号。为什么?因为中文更自然、更流畅、更真实,别人一看就愿意停下来。你自己舒服,读你的人也舒服。

比如我现在的主页就是全中文,偶尔会发类似GM这样的简单问候,但核心内容都是中文。

**最怕的是中英混在一起**,风格上会变得很漂浮,让人不知道你到底想吸引谁,主页看起来很乱。

当然,如果你本来就在全球跑,而且英文表达很顺,那也可以做英文号,但**别做得不三不四的**。

**重点是:你的定位要能让别人一眼看懂你是谁。**

就像给投资人介绍自己业务时一样——能否用一句话描述你的商业模式?你的账号定位也应该这么清晰。

***


# 个人简介

当我们选择好了赛道和语言以后,首先需要改的是头像、昵称和个人简介,这是**提升记忆度最快的地方**。

在X上面推荐用个人照片来做头像,这里不是指证件照,是合适的、美美的、帅帅的照片。

我本人不够帅,所以用了一个动漫头像,哈哈哈哈。

**注意名字和头像不要天天换,这是你的品牌。**



## 个人简介怎么写

接下来最重要的是个人简介内容怎么写。

它是你的**第一印象名片**,就像我们相亲时的自我介绍,目的是快速吸引粉丝、展示个性或专业性。写得好,能帮你涨粉、找合作;没写好,就容易被忽略。

这边我推荐采用**金字塔原则**,从重要到次要:

**身份/卖点 + 经历/经验 + 呼吁/广告**

拿我自己的举个例子:

**身份/卖点:** AI Coding / Agent 实战派

**技能/经历:** 帮编程新手和老板用 AI 把想法做成工具、产品和内容

**呼吁/广告:** 分享教程、工具和 AI 资讯 |合作 V:bozhou_ai
