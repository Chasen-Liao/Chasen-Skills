# 第一条推文怎么发

我刚进入一个新的圈子，那么我们应该怎么做？

当然是好好的介绍一下我们自己，让大家认识你以此来吸引第一批关注

这里我介绍不是说一下自己的TiTle，年龄，职位什么的，要的是输出一个故事，一个自己的，真实的故事。

这里我做两个案例分享，大家可以参考一下

# 案例一

```
2个月前, 32岁的我裸辞了, 奔赴妻子的家乡：法国图卢兹.
为什么我放弃了年薪70万的工作?
是这样的，我之前在图卢兹空客总部工作时候认识了妻子
为了更好的生活，我选择一个人去了巴黎的风险对冲软件公司
但后来，我厌恶了, 上班,  做10个小时的琐事, 下班, 就是为了维持麻木且安逸的生活.
而且在3月末结婚后, 妻子一直失眠, 状态不是很好
所以我决定结束在巴黎独居的生活.
去做我真正想做的事情, 创业.
从今年元旦开始，我每天6点学习做Youtube，无偿分享很多
- 工作流
- AI demo
- n8n教程
收获了7960个热心的粉丝和3位老板的认同.
我坚信只要给别人提供超额的价值，生活也会同样馈赠予我。
经历了那么多, 我想明白了一个道理
只有克服没有稳定收入的恐惧、和爱的人一起生活，才能把人生方向盘完全握在自己手里。
```

![第一条推文案例一](https://r2notes.bozhouai.com/x-growth-manual/first-post/4b8d37b4d14edc7d685f20943ffc3dff90eb7dce3e4e47e8b7fbe3b2f8433897.png)

这是一位老哥的起号故事，两天涨粉两千多，非常的羡慕，那么他为什么能够吸引这么多人关注？我做个简单的拆解

1. 高度共鸣，裸辞+创业+爱情的故事引起了大量职场人的共鸣，很多人都有这种想法，但是不敢去做，看到别人做了就会特别羡慕
2. 真实感，他没有藏着掖着，坦白说妻子失眠，自己每天6点起来学习，这种脆弱感反而让人觉得真实可信。而且他还有价值输出，分享了很多AI教程，让人觉得这个人靠谱
3. 视觉冲击，4张埃菲尔铁塔的照片，浪漫氛围直接拉满，法国背景+跨国婚姻，满足了大家的好奇心，评论区一堆人在问怎么娶国外老婆

# 案例二



```
2021/3/5，被大股东踢出亲手创建的公司，这次失败也是我赚2.2亿现金流的开始

刚从公司出来，收入断档，1500万的上海浦东别墅成了我的催命符。

筹了110万做骑享租电动车平台，打破强制骑手买车的模式，刚开始亲自上阵，和20个销售一个月跑断腿才做了26单，收入不到500。

同时妻子和我都很忙，为了孩子的教育争吵不断，让他们两被老师当成差生对待。她不理解我，为什么就是不肯向老公司认错换取安稳，各种原因导致我们的婚姻走向了终点，那时的我染上了烟瘾，整夜失眠。

后来又因为疫情，业务停滞，所有的坏事都叠加到了一起

绝境中，一家金融公司看中我的市场经验，我抓住了救命稻草，靠这笔业务成功渡过了难关。

凭借着租赁模式的低门槛优势，快速拿到疫情后激增的外卖骑手市场，并与美团最大的代理商达成合作。

实现了令人惊叹的成果：日订单峰值近5000，累计服务103.45万订单，一年便沉淀出2.2亿的稳健现金流。

连续创业让我明白：每一次创业，都是为下一次创业积累能量，所有的经历都不会白费

现在，我又为什么玩推特？因老公司亏损，连带我亏了2000多万。感兴趣的话，下次我讲讲那个故事
```

这个案例更硬核一些，血泪史，但是也是涨粉上千，为什么？

1. 情绪过山车，开头就是被踢出公司、别墅压力、婚姻破裂、疫情叠加，一堆坏事，让人看着就心疼。然后突然转折，抓住机会，做到2.2亿现金流，这种反转让人看得爽
2. 证据链，他不是光说，还放了离婚判决书、护照、奖杯、业务数据，这些图片就是证据，让人没法质疑，真实感爆棚
3. 有干货，他讲了自己怎么做的，租赁模式、美团合作、抓住疫情后的外卖市场，这些都是实打实的经验，不是空谈
4. 留钩子，最后说老公司亏了2000万，下次再讲，这就让人想关注他，等着看后续

# 这两个案例的共同点

看完这两个案例，你会发现他们都有几个共同的特点：

第一，故事要真实，不是编的，要有细节。第一个案例说妻子失眠，自己每天6点起床，第二个案例说和20个销售跑断腿才做了26单，这些细节让人觉得这是真事儿，不是鸡汤。

第二，要有情感冲击。裸辞、创业、爱情、婚姻破裂、绝地反击，这些都是能触动人的点。你不一定要有这么戏剧化的经历，但是你得有能让人有感觉的东西。

第三，最好有证据。图片、数据、成果，这些都能增加可信度。第一个案例有巴黎的照片，第二个案例有判决书和业务数据，这些都是加分项。

第四，要有价值输出。你不能光讲故事，还得让人觉得关注你能学到东西。第一个案例分享AI教程，第二个案例分享创业经验，这样人家才愿意关注你。

# 如果你没有这样的故事怎么办

看到这里，你可能会想，我没有这么精彩的故事啊，我既没有裸辞去法国，也没有被踢出公司再逆袭，那我还能不能玩X？

当然可以。

如果你暂时想不到自己有什么故事可以讲，那就先跳过这一步，不要硬憋。你可以通过和大V互动的方式来度过冷启动阶段，也就是0到1000粉这个阶段。

具体怎么做，我会在后面的章节详细讲。

总之，第一条推文不是必须的，但是如果你有故事，那就好好讲，这能帮你快速吸引第一批粉丝。如果没有，也别着急，慢慢积累，先从互动开始。
