# X 增长手册

面向 X（Twitter）账号从注册、定位、冷启动到互动增长的操作手册。

## 不同阶段，重点不一样

在开始之前，先说清楚一件事：不同粉丝量级该做的事情是不一样的，不要一上来就什么都做。

**1000 粉以内：以互动为主。** 这个阶段你自己发帖基本没有流量，硬发是最低效的。主要精力应该放在跟大V互动上，去蹭大V的流量，先把最初的曝光和粉丝攒起来。

**1000 到 3000 粉：以内容为主。** 有了基础粉丝之后，重心转向输出干货内容。这个阶段要多写、多发，把自己的内容能力和网感练出来。

**3000 粉以上：可以启动变现。** 到这里可以开始接商单、给自己的产品引流了。我认为 **3000 粉基本可以算冷启动结束**，你已经是一个小博主了。接下来就是继续分享干货，不断成长。
