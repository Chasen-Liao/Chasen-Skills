# Metrics — X Analytics 指标定义

- **Impressions**：曝光，基础分母
- **Engagements / ER**：`Engagements / Impressions`，互动率。>15% 为高互动（争议型），8-15% 健康
- **Bookmarks / BR**：`Bookmarks / Impressions`，收藏率。>0.8% 为资产型爆款
- **Profile visits / PR**：`Profile visits / Impressions`，主页率。>0.5% 为涨粉型
- **New follows**：关注转化，`New follows / Profile visits` 主页→关注 8-14% 为正常
- **Detail Expands**：详情展开率，2-3% 正常
- **URL Clicks**：链接点击，Pi 类通常占 70%+

漏斗：`Impressions → Detail (1.8-2.6%) → URL/Profile (0.2-0.9%) → Follows (0.02-0.03%)`
